# Znap-OsuBackground

Custom osu! background overlay for OBS, compatible with **tosu**.

<a href="https://github.com/znapppp" target="_blank"><img height="35" src="https://img.shields.io/badge/github-000000?style=for-the-badge&logo=github&logoColor=white" /></a>

| Property | Details |
| --- | --- |
| **Usage** | OBS Overlay / In-game |
| **Compatible with** | tosu |
| **Resolution** | 1920x1080 |

> Background switcher overlay with arbitrary width and height.

## Features
- Dynamic osu! beatmap background display
- Supports customizable overlay styling and dimensions via `settings.json` and `styles.css`
- Real-time sync with tosu websocket
